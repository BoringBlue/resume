# BoringBlue 的在线简历

这是一个使用原生 HTML 和 CSS 构建的 GitHub Pages 简历站点。

## 本地预览

在当前目录执行：

```bash
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080>。

## GitHub Pages

仓库：`BoringBlue/resume`

在 GitHub 中进入 `Settings -> Pages`，选择 `Deploy from a branch`，使用 `main` 分支的 `/root` 目录。

发布后网址：<https://boringblue.github.io/resume/>
